# 🎨 Kiiaara Portfolio Website

Personal portfolio website showcasing gaming, streaming, and automation projects.

**Stack:** HTML5 + CSS3 + Vanilla JavaScript + AOS animations

---

## 📋 Overview

Responsive portfolio landing page featuring:
- ✅ Game reviews & gaming content
- ✅ Streaming projects & achievements
- ✅ Automation & tech projects
- ✅ Smooth scroll animations (AOS library)
- ✅ Social media links & contact
- ✅ Mobile-optimized design

---

## 🎯 Sections

1. **Hero** - Introduction with animated background
2. **Projects** - Game guides, streams, automation workflows
3. **About** - Skills, tech stack, interests
4. **Contact** - Social links, email, resume

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JS
- **Animation:** AOS (Animate On Scroll) library
- **Images:** WebP format (optimized)
- **Hosting:** Static hosting (Vercel, Netlify, GitHub Pages)

## 🚀 Quick Start

### Local Development
```bash
# Simply open in browser
open index.html

# Or use a local server
python -m http.server 8000
# Open http://localhost:8000
```

### Deploy to Vercel
```bash
npm i -g vercel
vercel
```

### Deploy to GitHub Pages
```bash
# Push to gh-pages branch
git subtree push --prefix . origin gh-pages
```

## 📝 Customization

### Edit Content
1. Open `index.html` in editor
2. Modify sections, add new projects
3. Update social links
4. Replace images in root folder

### Add New Project
```html
<div class="project-card">
  <img src="your-image.webp" alt="Project">
  <h3>Project Title</h3>
  <p>Description</p>
  <a href="#">Learn more</a>
</div>
```

### Update Styling
Edit `aos.css` for global styles or add inline `<style>` tags.
